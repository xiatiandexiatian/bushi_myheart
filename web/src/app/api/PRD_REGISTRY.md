# PRD 总集（台账）

| 版本 | 标题 | 需求内容（详细摘要） | PRD链接 |
| --- | --- | --- | --- |
| PRD-001 | 不失（MVP） | 面向单人自用的私密记录空间，目标是在任何状态下留下真实，并在未来被温柔唤起。范围包含即时多形态记录、默认私密与登录访问、被动回顾与手动切换、粗时间视角与轻量提示、基础检索兜底。记录可为空但保存需至少一种类型，语气保持叙述性不评判。回顾与时间视角仅做展示与聚合，不做分析与建议。非目标为社交分享、效率管理与公开发布，异常提示需温和可恢复。 | docs/prd/PRD-001.md |
| PRD-002 | 不失（MVP）- V0.2 | 在 V0.1 基础上补齐 AI 对话入口、文件上传与媒体预览、轻量自我观察（智能体生成一句话+相关记录）、弹窗展示相关记录、粗时间视角改为 3/10/30 天并显示真实条数、这些时刻分页（每页 6 条）。智能体触发规则：刷新/新增>=7/手动点击；失败兜底显示最近 3 条记录。 | docs/prd/PRD-002.md |
